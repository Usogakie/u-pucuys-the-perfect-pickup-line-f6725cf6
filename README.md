One short pickup line an AI agent could actually say out loud: a machine that can predict the next word in any sentence — except the one where you say yes. `main.py` writes it, deterministically and with no network, to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt`.

## Run it

```sh
python3 main.py
```
